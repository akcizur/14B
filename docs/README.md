## Principy projektu

- jeden dům a jedna ulice jako stavební reference;
- žádné domýšlení rozměrů otvorů nebo dispozic;
- interiér odpovídá skutečné geometrii exteriéru;
- bez interiérového vybavení před schválením konstrukce;
- pouze Free Play / Sandbox.
