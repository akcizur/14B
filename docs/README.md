# District 14 documentation

Project documentation is split into **setting/lore** and **technical implementation**. Lore defines what the world is and its approved fictional rules. Technical documents describe code, geometry, tests, and production constraints.

## World lore

- [Lore index](lore/README.md): canon status, document map, and documentation policy.
- [World Lore](lore/WORLD-LORE.md): premise, setting pillars, tone, spatial identity, and canon boundaries.
- [Starship Ring Habitat](lore/RING-HABITAT.md): the protective ring, visual presence, open design decisions, and constraints.
- [Three Streets](lore/THREE-STREETS.md): exactly three streets, their hierarchy, and masterplan requirements.
- [Artificial Atmosphere](lore/ARTIFICIAL-ATMOSPHERE.md): sky, haze, lighting, environmental depth, and open questions.
- [Visual Identity](lore/VISUAL-IDENTITY.md): architecture, retro-futurist technology, materials, and composition.
- [Lore Change Log](lore/LORE-CHANGELOG.md): dated worldbuilding decisions.

## Technical documentation

- [Reference House & Street](REFERENCE-HOUSE-AND-STREET.md): measured GLB dimensions, entrance, floors, stairs, windows, glazing, and street profile.
- [World Architecture](WORLD-ARCHITECTURE.md): module boundaries, metric contract, and scene lifecycle.
- [Settlement Growth](SETTLEMENT-GROWTH.md): controlled expansion planning and gates.
- [Verification Log](VERIFICATION-LOG.md): tests, builds, deployment, and visual inspection.

## Project principles

- Treat the habitat lore as the setting baseline; don't silently alter it.
- Exactly three streets: one long dominant Main Street and two subordinate streets. No procedural street-grid expansion.
- Do not guess dimensions for model openings or floor layouts.
- Interiors must match exterior geometry.
- Do not add interior furnishings before structural layout is approved.
- Active mode remains Free Play / Sandbox.
- Record durable decisions, corrections, rejected ideas, and significant discoveries in documentation.
